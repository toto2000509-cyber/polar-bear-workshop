# تنظيم صور المنتجات

احتفظ بالصور الأصلية الحالية في مجلد `ملف الصور/` وبالنسخ القديمة في هذا المجلد دون حذف أو تعديل. أضف نسخ العرض الجديدة بصيغة WebP داخل مجلد المنتج المناسب هنا. راجع `README-media-ar.md` في جذر المشروع لدليل المجلدات والمسارات وإعادة التحويل.

صيغة التسمية المقترحة:

`product-purpose-number.webp`

مثال: `dome-hero-01.webp` أو `machine-bending-01.webp`.

لا تُدرج صورة في الموقع على أنها من تنفيذ الورشة إلا بعد اعتمادها.
