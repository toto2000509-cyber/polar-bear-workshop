# تنظيم صور المنتجات

احتفظ بالصور الأصلية الحالية في مجلد `images/` دون تعديل. أضف الصور الجديدة بصيغة WebP أو JPG داخل مجلد المنتج المناسب هنا.

صيغة التسمية المقترحة:

`اسم-المنتج-رقم-المشروع-نوع-الصورة.webp`

مثال: `قبة-001-واجهة.webp` أو `مكينة-تقويس-001-تفاصيل-01.webp`.

لا تُدرج صورة في الموقع على أنها من تنفيذ الورشة إلا بعد اعتمادها.
