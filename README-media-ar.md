# دليل الصور والمعاينة المحلية

تم تطوير بداية الصفحة الرئيسية وتنظيم نسخ العرض محليًا، دون حذف الصور الأصلية أو تعديلها. النشر يتم بعد اعتماد صاحب المشروع. المشروع موقع HTML وCSS وJavaScript ثابت، ولا يحتاج عملية بناء أو قاعدة بيانات.

## تنظيم الوسائط

```text
ملف الصور/                         الأصول العربية؛ احتفظ بها كما هي
assets/
  images/
    domes/
      hero/                        صور القبة في بداية الرئيسية
      gallery/                     صور معرض القباب ومواصفاتها
    machines/                      مكائن تقويس الحديد
    trailers/                      العربات والمقطورات
    greenhouses/                   البيوت المحمية الزراعية
    car-shades/                    مظلات السيارات
    brand/                         شعار الورشة
    backgrounds/                   خلفيات المشروع السابقة
    media-manifest.json            مصدر وأبعاد وحجم كل نسخة جديدة
  videos/                          محجوز لفيديوهات مستقبلية؛ غير مستخدم حاليًا
```

الملفات السابقة في `assets/images/` باقية، حتى بعد تحديث الموقع لاستخدام النسخ الجديدة. مجلد `images/` القديم كان غائبًا أصلًا عند بدء التنفيذ، وسجل Git يعرض حذف ملفاته مسبقًا؛ لم يُحذف ضمن هذا العمل. الأصول الحالية موجودة في `ملف الصور/` والنسخ السابقة في `assets/images/`.

حزمة النشر تستخدم نسخ العرض داخل `assets/`. الأصول العربية ومجلد `preview/` ملفات عمل محلية؛ لا يلزم رفعها لتشغيل الموقع، ويحتاج سكربت إعادة التحويل إلى الأصول المحلية المذكورة في بيان الصور.

## صور بداية الصفحة الرئيسية

- `domes/hero/dome-hero-01.webp`: مشهد القبة الخارجية؛ مصدره `قبة شفافة بستة كراسٍ على سطح سعودي.png`.
- `domes/hero/dome-hero-02.webp`: الجلسة الداخلية؛ مصدره `جلسة قهوة عربية داخل قبة شفافة-5.png`.
- `domes/hero/dome-hero-03.webp`: المشهد المسائي؛ مصدره النسخة السابقة `domes/dome-night-01.jpg`.
- نسخة `-640.webp` لكل مشهد مخصصة للشاشات الأصغر، ويختار المتصفح الحجم عبر `srcset`.

ضع صور الواجهة المقبلة في `assets/images/domes/hero/` بأسماء إنجليزية مثل `dome-hero-04.webp`. أضف المشهد ونصه وزر اختياره في `index.html`، وحدّث ترقيم المشاهد والعدد الكلي الظاهر. عند استبدال صورة حدّث `width` و`height` وقيم `srcset` وفق أبعادها الحقيقية.

السلايدر يستخدم تلاشيًا هادئًا كل 7 ثوانٍ؛ يتوقف عند مرور المؤشر أو التركيز داخله أو خروجه من مجال الرؤية أو إخفاء التبويب. التنقل اليدوي يوقف العرض التلقائي حتى اختيار تشغيله مجددًا. تفضيل تقليل الحركة يعطّل التشغيل التلقائي. يمكن التنقل بالأزرار وأسهم لوحة المفاتيح وHome وEnd، أو بالسحب على الصورة في الجوال. عند تعطيل JavaScript يبقى أول مشهد والزرّان ظاهرين.

## صور المنتجات والهوية

ضع بقية الصور في مجلد نوع المنتج، مثل:

| الاستخدام | المثال |
|---|---|
| معرض القباب | `assets/images/domes/gallery/dome-gallery-01.webp` |
| داخل القبة | `assets/images/domes/gallery/dome-interior-01.webp` |
| صور الورشة والمواصفات المحضّرة للمستقبل | `dome-workshop-01.webp` و`dome-specifications-01.webp` داخل `gallery/` |
| المكائن | `assets/images/machines/machine-bending-01.webp` |
| المقطورات | `assets/images/trailers/trailer-01.webp` |
| البيوت المحمية | `assets/images/greenhouses/greenhouse-01.webp` |
| المظلات | `assets/images/car-shades/car-shade-01.webp` |
| الشعار | `assets/images/brand/brand-logo-01.webp` |

النسخ WebP مضبوطة النسب، دون قص أو تكبير للأصل، والشعار يحافظ على الشفافية. جميع نسخ العرض الجديدة وعددها 26 تشغل نحو 3.25 ميغابايت، مقابل 24.10 ميغابايت للمصادر الفريدة؛ هذا مجموع الملفات وليس حجم التحميل عند فتح الصفحة. الصورة الأولى فقط ذات أولوية تحميل مرتفعة، وتُحمّل بقية مشاهد الواجهة عند الحاجة، وصور بطاقات المنتجات مؤجلة التحميل.

تعرض الواجهة الصور كاملة باستخدام `object-fit: contain`؛ المساحات حول الصور العمودية مقصودة لحماية المحتوى من القص. لم تُنشأ صور بالذكاء الاصطناعي ضمن هذا التطوير، واستُخدمت الملفات المتاحة في المشروع. لا تعتمد صورة على أنها تنفيذ فعلي للورشة إلا بعد اعتمادها، وفق توثيق المشروع السابق.

لإعادة تجهيز الوسائط بعد تحديث المصادر: `node scripts/prepare-media.cjs`. يحتاج السكربت Node.js وحزمة `sharp`؛ استُخدمت الأدوات المتاحة محليًا في بيئة Codex دون تثبيت حزم. راجع قائمة المصادر في السكربت، فهو يكتب نسخ العرض وملف البيان فقط ولا يغير الأصول.

## الملفات المعدلة والمضافة

- `index.html`: البداية الجديدة، السلايدر وأزراره، صور البطاقات ومساراتها؛ أُزيل طلب خط Google غير مستخدم.
- `assets/css/hero.css` و`assets/js/hero-slider.js`: تصميم الواجهة وسلوك السلايدر، ملفان جديدان مستقلان.
- `assets/css/styles.css`: ربط الشعار المحسّن، إضافة Tahoma كخط احتياطي محلي، وضبط رأس الجوال لمنع التمرير الأفقي. يظل خط Thmanyah السابق معتمدًا على مصدر خارجي عند توافر الإنترنت.
- `assets/js/main.js`: إصلاح استعادة التمرير بعد إغلاق قائمة الجوال باختيار رابط.
- صفحات `products/` الخمس: صور WebP وأبعاد صحيحة ووصف مطابق لمعرض التكبير الحالي.
- `assets/images/README.md`: تحديث دليل الأصول والتسمية.
- `assets/images/media-manifest.json` و`scripts/prepare-media.cjs`: بيانات التحويل وسكربته.
- `scripts/serve-local.cjs` و`scripts/start-preview.ps1`: خادم معاينة محلي دون حزم إضافية.
- `preview/verify-home.cjs` و`preview/hero-verification.json` و`preview/hero-desktop.png` و`preview/hero-mobile.png`: التحقق ولقطات المعاينة الجديدة. ملفات المعاينة القديمة باقية.

## المعاينة

من طرفية PowerShell داخل جذر المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-preview.ps1
```

افتح `http://127.0.0.1:4173/` وأوقف الخادم بـ`Ctrl+C`. السكربت يستخدم Node.js المثبت أو وقت التشغيل المحلي المتاح لـCodex. إذا كان الخادم يعمل بالفعل فاكتفِ بفتح الرابط. يمكن أيضًا فتح `index.html` مباشرة أو استخدام Live Server في VS Code. خادم المعاينة يستمع على `127.0.0.1` فقط ولا ينشر الموقع.

للتحقق الآلي اختياريًا: شغّل `node preview/verify-home.cjs` مع توافر Playwright وChrome والخادم المحلي. التحقق يمنع الطلبات الخارجية ويختبر بديل الخط المحلي، ويكتب تقريره ولقطتي المعاينة في `preview/`.

اجتازت النسخة النهائية 54 فحصًا للواجهة والمنتجات، مع عدم وجود مسارات محلية مكسورة أو أخطاء JavaScript. واجتازت المشاهد الثلاثة 12 حالة إضافية بعرضي 320 و390 بكسل عند تكبير النص إلى 200%، دون تداخل أو قفز في الارتفاع؛ تفاصيلها في `preview/hero-accessibility-verification.json`. جرى أيضًا التحقق من توقف تبديل المشهد إذا طُلب الإيقاف أثناء انتظار تحميل صورته.
